# 本地 TVBox 配置文件夹

在 Windows 桌面版或 Android App 的「设置 → TVBox 配置」中点击「加载本地配置文件夹」，选择包含主配置、JAR 和规则文件的目录。

- 加载目录只列出候选文件，不默认选中、不替换当前网络配置。随后在「本地主配置」下拉框手动选择一个文件，才读取并应用该配置。
- 下拉框保留，之后可以继续切换主配置；记住手动选择，重新展开时定位到选中项。切换网络资源时，本地下拉显示「选择本地主配置」，不同时高亮两个来源。
- 自动发现目录及三层子目录内包含 `sites`、`urls` 或 `lives` 的 `.json`、`.json5`、`.txt`、`.conf` 文件。多个候选按文件名自然排序。
- JAR、规则文件、子配置和直播列表保持目录结构，配置使用相对路径，如 `./jar/spider.jar`、`./rules/site.json`。本地规则 `ext` 也支持 `rules/site.json` 这种写法。
- 资源留在原目录中，只读访问；不复制、不上传。请保留该目录及 Android 文件夹读取授权；目录移动或权限失效时需要重新选择。
- Windows 仍只运行 PC 兼容源，导入本地 JAR 不代表 Windows 可以执行 Android 插件。Android 继续使用现有 CSP/JAR 宿主，具体插件兼容性取决于插件本身。
- 浏览器预览不提供本地目录服务，需使用桌面版或 Android App。
