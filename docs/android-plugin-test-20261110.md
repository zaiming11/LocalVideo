# Android 插件真机检查（2026-11-10）

设备：PJE110，Android API 36，arm64。正式包从 1.0.3 升级到 1.0.4（versionCode 104），沿用原包名及签名，保留数据。

## 修复内容与证据

1. **配置请求**：原正式 APK 导入列表最后的“游魂多仓”返回 HTML，电脑可读到 JSON。同一手机改用 HttpURLConnection 后成功读取 24 个仓库。请求保留来源 User-Agent、gzip/字符集及重定向后的地址，跨域重定向移除账号认证头，配置请求与插件调用使用不同执行队列。
2. **正式包的二次类加载**：相同插件在独立测试宿主正常，正式 APK 的 BaseSpiderGuard.init 却得到空 Spider。uni-app 的宿主接口位于子 DEX loader，原 Application 的 loader 无法看到接口。通过 Application 门面提供宿主 loader，并转发真实 Application 的生命周期注册；工作线程设置并恢复 context loader。正式 APK 的“游魂多仓 → 饭太硬 → 豆豆片单”复测不再报 NullPointerException，分类和影片正常。
3. **相对 ext 路径**：`./json/Dm84.json` 原样传给 XBPQ 时触发数组越界。现在按最终配置 URL 补全，仅改相对路径字符串，保留内联 JSON 和不透明参数。手机插件调用复测“动漫巴士1”返回 4 个分类，未再越界；分类内容仍为空，不宣称该源可以播放。
4. **地址附带请求头**：实测插件返回 `poster.jpg@Referer=...@User-Agent=...`。此前整串被当作图片 URL，导致海报空白。现拆分 URL 与请求头并交给媒体代理，详情海报及播放地址同样处理。最终正式 APK 的王二小页面已目视确认海报加载。
