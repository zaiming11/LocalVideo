# 本地影库 · Windows 1.1.0-alpha.8 / Android 1.0.8

- Windows 和 Android 默认通过 Netlify 检查并下载安装包，不再依赖 GitHub 公共镜像作为默认更新链路。
- “应用更新”中可切换 Netlify 与 GitHub；GitHub 的自动加速、直连和自定义镜像继续保留。
- Windows 更新包在 Netlify 分片下载后自动合并，核验完整 SHA-256 后由用户确认安装；Android 下载完整 APK，继续校验大小、SHA-256、包名、实际版本与签名。
- 保留安卓无全局 `URL` 接口时的检查更新兼容修复。
- Netlify 网页版同步更新，使用浏览器播放器和公共 HTTP 资源代理；原生插件执行能力仍按 Windows、Android 和浏览器分别提供。

## 下载与安装

- [Netlify 在线版及更新服务](https://localcinema-zaiming11.netlify.app)
- [Android 1.0.8 ARM64（Netlify 直接下载）](https://localcinema-zaiming11.netlify.app/updates/LocalVideo-1.0.8-Android.apk)
- [Windows 1.1.0-alpha.8 安装版（GitHub）](https://github.com/zaiming11/LocalVideo/releases/download/v1.1.0-alpha.8-android-1.0.8/LocalVideo-1.1.0-alpha.8-Windows-x64-Setup.exe)
- [Android 1.0.8 ARM64（GitHub 备用）](https://github.com/zaiming11/LocalVideo/releases/download/v1.1.0-alpha.8-android-1.0.8/LocalVideo-1.0.8-Android.apk)

旧版不包含双渠道界面时，需先手动覆盖安装本版，随后默认使用 Netlify 更新。Android 沿用原包名及签名，覆盖安装保留数据。Windows 当前为测试版。

本项目发布同时包含 GitHub 和 Netlify，更新清单记录实际安装包版本、大小及哈希，不用旧安装包冒充新版本。
