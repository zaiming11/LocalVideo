# 本地影库 · Windows 1.1.0-alpha.6 / Android 1.0.6

- Windows 将 LibVLC 视频及控制层嵌入主窗口，支持返回、播放列表、切集、暂停和进度操作，修复退出全屏后控制层尺寸异常。
- 修复 Windows HLS 播放列表在 Range 响应下的分片及密钥地址重写，改善带请求头的视频播放。
- Android 新增 JS/drpy 和 Python 3 Spider 支持；Python 运行时首次使用时按需下载并校验，Python 功能需要 Android 7.0 或更新版本。
- 对部分短暂连接中断进行有限重试，改进站点错误提示、资源选择和片单空状态。具体源能否取得内容或播放仍取决于上游服务与脚本依赖，尚不支持通用网页嗅探。
- 保留 GitHub 镜像更新、下载校验和用户确认安装。
