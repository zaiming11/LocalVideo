# 本地影库 · Windows 1.1.0-alpha.9 / Android 1.0.9

- Windows、Android 和网页版在“设置 → 关于 → 应用下载”统一提供二维码，支持放大及复制链接。二维码使用固定的完整 EXE、APK 和网页版地址。
- 媒体库直接显示搜索框，输入即可筛选本地视频；移除顶部 TVBox、搜索和添加按钮组，导入入口保留在媒体库和设置中。
- 网页端支持加载本地 TVBox 配置文件夹，手动选择主配置，读取相对路径子配置、直播列表和图片。文件仅保存在当前浏览器，刷新后可恢复；文件改动后需重新选择。网页端不执行 Android JAR / DEX 插件。
- 继续提供 Netlify 默认更新渠道及 GitHub 备用渠道。Windows 仅发布安装版，Android 为 ARM64，沿用原包名和签名。
