# 本地影库 · Windows 1.1.0-alpha.5 / Android 1.0.5

- 更新服务改为 GitHub Releases，无需填写账号密码；已有坚果云配置自动迁移并保留自动检查偏好。
- 默认通过加速镜像检查和下载，失败后重试 GitHub 直连。可在“设置 → 关于 → 应用更新”中切换直连或自定义 HTTPS 镜像。
- 下载后校验文件大小及 SHA-256；Android 还会检查包名、签名和真实版本，由用户确认覆盖安装。
- 集成 LibVLC 播放器，支持本地视频及 TVBox 播放、续播、倍速、横竖屏全屏和锁屏控制。Windows 支持 PC 兼容的 HTTP 接口与直播源；Android 支持其原生插件接口。
